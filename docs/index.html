Core Submodules

Seven highly specialized, strictly isolated components operating seamlessly as clean Git submodules.

sovereign-cli

High-performance Go CLI powered by Cobra, Viper, and Zap logger for rapid system telemetry and control.

Go / Cobra

sovereign-ui

Modern Next.js App Router dashboard featuring Shadcn-UI, Tailwind CSS, and real-time SSE metrics.

Next.js / React
🛡️

no-mistakes

The core pipeline execution engine enforcing git safety, PR routing, and stringent verification invariants.

Go / Engine
🧠

codebase-memory-mcp

Knowledge Graph MCP server for deep semantic code discovery, Cypher queries, and AST path tracing.

sovereign-security

Zero-trust secret scanner and compliance auditor ensuring absolute credential safety across all commits.

Persistent memory ledger and audit store backing Sovereign-OS system states securely across runs.

Go / Ledger

Dynamic adaptation engine managing intelligent auto-remediation policies and runtime strategy tuning.
